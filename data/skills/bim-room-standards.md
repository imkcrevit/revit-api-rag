# BIM 房间建模与命名规范

> 适用范围：所有 Revit 房间（Room）相关的创建、修改、统计与导出操作。
> 当用户提到「房间 / Room / 空间 / 户型」时本规范自动生效。

## 一、房间命名规则

房间名称采用 **`功能_序号`** 或 **`楼层-业态-序号-功能`** 两种之一，禁止留空或使用默认 "Room"。

| 业态 | 推荐命名格式 | 示例 |
|------|--------------|------|
| 住宅 | `户型代号-空间功能` | `A1-主卧`、`B2-起居室` |
| 办公 | `功能_序号` | `办公室_0301`、`会议室_0205` |
| 商业 | `楼层-铺位号-业态` | `1F-S101-餐饮` |
| 公建 | `楼层-功能-序号` | `2F-教室-201` |

### 必填参数（创建房间时强制要求）

| 参数 | 类型 | 说明 |
|------|------|------|
| `Number` | string | 房间编号，**全项目唯一** |
| `Name` | string | 房间名称，遵循上表格式 |
| `Level` | Level | 所属标高 |
| `Department` | string | 所属部门/区域（可选但建议） |
| `Comments` | string | 备注，记录特殊要求 |

## 二、房间边界与分隔

1. **墙体作为边界**：默认使用墙、柱、楼板作为房间边界（`Room Bounding = true`）。
2. **房间分隔线**：开放空间（如大堂、中庭）必须使用「房间分隔线（Room Separation Line）」明确划分，禁止留下未闭合区域产生 *Not Enclosed* 错误。
3. **跨标高房间**：层高超过 5 米的中庭、楼梯间应启用「Upper Limit + Offset」设置房间高度，而非默认 2400mm。

## 三、面积与净高校验规则

| 房间类型 | 最小净面积 | 最小净高 | 来源 |
|----------|------------|----------|------|
| 卧室 | 5.0 m² | 2.40 m | GB 50096-2011 |
| 起居室 | 10.0 m² | 2.40 m | GB 50096-2011 |
| 厨房 | 3.5 m² | 2.20 m | GB 50096-2011 |
| 卫生间 | 1.8 m² | 2.20 m | GB 50096-2011 |
| 普通办公室 | 4.0 m²/人 | 2.50 m | GB 50352-2019 |
| 中小学普通教室 | 1.36 m²/座 | 3.00 m | GB 50099-2011 |

> 当 LLM 生成创建房间的代码或参数时，**必须**在备注中说明面积是否满足上表，若不满足应在 `Comments` 字段加 `⚠ 面积不达标` 标记。

## 四、防火分区与疏散（公建场景）

1. 每个房间必须能追溯到唯一的「防火分区」编号，使用 `FireZone` 共享参数记录，如 `FZ-1F-01`。
2. 疏散房间（如会议室≥50人）应额外标注 `EvacuationCapacity`（人数）与 `EvacuationDistance`（最远疏散距离 m）。

## 五、生成代码时的强制约束（给 AI 的硬性规则）

- 创建房间使用 `Document.Create.NewRoom(Level, UV)` 或 `NewRoom(Phase)`，**禁止**使用过时 API `Document.Create.NewRooms`（无参版本）。
- 批量创建房间前，**必须**先调用 `Phase` 接口获取当前阶段并显式传入。
- 使用 `Room.Area` 读取面积时必须先判断 `Room.Location != null`，否则会拿到未放置房间。
- 房间命名涉及中文时，**禁止**使用 GBK 编码写入参数，必须确保 .NET 字符串以 UTF-16 传递。

## 六、反模式（Anti-Patterns）

| 错误做法 | 为什么错 | 正确做法 |
|----------|----------|----------|
| 直接用 "Room 1" 作为名称 | 无业务含义，无法统计 | 使用业态命名规则 |
| 不设置房间编号 | 明细表无法排序、引用失败 | `Number` 字段必填且唯一 |
| 用 Filled Region 代替 Room | 不参与面积明细统计 | 必须用 Room |
| 房间边界跨越防火分区 | 违反消防规范 | 用分隔线切分 |
