# BIM 视图与图纸命名规范

> 适用范围：所有视图创建、复制、重命名，以及图纸（Sheet）的编号与图框放置操作。
> 用户输入包含「视图、平面、立面、剖面、详图、图纸、Sheet、View」时本规范自动生效。

## 一、视图命名规则

### 1.1 通用格式

```
<专业>-<视图类型>-<位置/对象>-<用途>
```

| 字段 | 取值 |
|------|------|
| 专业 | `建` / `结` / `给排` / `暖通` / `电气` / `综合` |
| 视图类型 | 平面、立面、剖面、详图、轴测、三维 |
| 位置/对象 | 楼层号、轴线区间、构件名 |
| 用途 | `提资`、`出图`、`分析`、`协调` |

### 1.2 各类视图命名示例

| 视图类型 | 命名示例 |
|----------|----------|
| 楼层平面 | `建-平面-F1-出图`、`暖通-平面-F2-提资` |
| 天花板平面 | `建-天花-F1-出图` |
| 立面 | `建-立面-东-出图`、`建-立面-1轴-出图` |
| 剖面 | `建-剖面-1-1-出图`、`结-剖面-A-A-分析` |
| 详图 | `建-详图-外墙节点-01` |
| 三维视图 | `综合-3D-机电协调`、`建-3D-透视-入口` |
| 区域平面 | `建-平面-F2-A区-出图` |

### 1.3 工作视图前缀

非出图的临时视图必须加 `WIP_` 前缀（Work In Progress），出图前清理：

- `WIP_建-平面-F1-临时检查`
- `WIP_综合-3D-碰撞-2026年5月`

## 二、视图样板（View Template）命名

```
VT_<专业>-<视图类型>-<出图比例>
```

**示例**：

- `VT_建-平面-1:100`
- `VT_结-平面-1:100`
- `VT_暖通-平面-1:100`
- `VT_综合-3D-轴测`

## 三、图纸编号规则

### 3.1 编号格式

```
<专业代码>-<类别>-<序号>
```

| 专业代码 | 含义 |
|----------|------|
| `JS` | 建筑（建施 JianShi） |
| `JG` | 结构 |
| `GP` | 给排水 |
| `NT` | 暖通 |
| `DQ` | 电气 |
| `ZH` | 综合 |

| 类别 | 取值范围 |
|------|----------|
| `00` | 目录、说明、总图 |
| `01` | 平面图 |
| `02` | 立面图 |
| `03` | 剖面图 |
| `04` | 详图 |
| `05` | 大样图 |
| `06` | 系统图（机电专用） |

**示例**：

- `JS-00-01` 建筑施工图目录
- `JS-01-01` 建筑首层平面图
- `JS-04-12` 建筑外墙节点详图 12
- `NT-06-01` 暖通系统图

|------|----------|
| JS-01-01 | 首层平面图 |
| JS-02-01 | 南立面图 |

## 四、浏览器组织规则（Browser Organization）

按以下层级组织视图浏览器：

```
专业 (建/结/机电/综合)
  └── 阶段 (新建/改造/拆除)
       └── 视图类型 (平面/立面/剖面/详图)
            └── 标高或编号
```

通过 `Project Browser Organization` 设置 + 自定义参数 `专业`、`阶段`、`视图类型` 实现。

## 五、图框（Title Block）

| 图幅 | 尺寸（mm） | 用途 |
|------|-----------|------|
| A0 加长 | 1189 x 1682+ | 总平面、复杂大平面 |
| A0 | 841 x 1189 | 平面、剖面 |
| A1 | 594 x 841 | 一般出图标准 |
| A2 | 420 x 594 | 详图、节点 |
| A3 | 297 x 420 | 小详图、说明页 |
| A4 | 210 x 297 | 目录、说明 |

> 图框族命名：`图框_<图幅>_<项目代号>.rfa`，如 `图框_A1_HSU2026.rfa`。

## 六、给 AI 的硬性约束

- 创建平面视图使用 `ViewPlan.Create(doc, viewFamilyTypeId, levelId)`，**禁止**复制已有视图后改 `levelId`（API 不允许直接改 Level）。
- 创建图纸使用 `ViewSheet.Create(doc, titleBlockTypeId)`，传入 `ElementId.InvalidElementId` 会创建无图框图纸（不推荐）。
- 在图纸上放置视图使用 `Viewport.Create(doc, sheetId, viewId, location)`，**位置坐标是图纸坐标系下的 XYZ**（单位英尺），需要转换。
- 设置视图样板使用 `View.ViewTemplateId = templateViewId`，应用后某些属性会被锁定，**不要**再去修改这些属性。
- 重命名视图使用 `View.Name = "新名"`，遇到重名会抛 `ArgumentException`，必须捕获。
- 修改图纸编号使用 `ViewSheet.SheetNumber`，**不要**改 `Name`（那是图纸名称不是编号）。

## 七、反模式

| 错误做法 | 为什么错 | 正确做法 |
|----------|----------|----------|
| 命名 `Floor Plan: Level 1` | 默认英文 + 冗余 | `建-平面-F1-出图` |
| 出图视图直接编辑参数覆盖样板 | 下次刷新样板被覆盖 | 复制副本作为出图视图 |
| 一个视图既用于提资又用于出图 | 双方刷新冲突 | 拆分两个视图 |
| 图纸编号留空 | 浏览器无法排序、打印混乱 | `<专业>-<类别>-<序号>` 必填 |
| 浏览器分类按"按楼层"单层 | 大项目找视图困难 | 多级分类（专业/类型/楼层） |
| 视图样板与视图比例不一致 | 出图比例错误 | 样板与比例打包命名 |
