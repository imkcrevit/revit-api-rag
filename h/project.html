V Data Pipeline
VI Tool Solidification

Principle

When generated code executes successfully, it crystallizes into a reusable YAML tool with parameterized placeholders. Next invocation skips RAG and LLM entirely.

Parameterization

LLM replaces hardcoded values with {placeholders} — wall types become {type_name}, levels become {level_name}, dimensions become {width}. Each annotated with type and optional choices_from.

Dynamic Choices

Parameters with choices_from query the live Revit model. "levels" fetches actual level names, "family_types:OST_Walls" fetches wall types in the current project. User selects from a list — never types manually.

Storage

Tools stored as human-readable YAML in /mcp_bridge/tools/. Version-controllable, exportable, composable. Includes metadata: creation date, source query, execution count.

YAML Tool Example 
name: create_structural_column
display_name: Create Structural Column
description: Place a structural column at specified coordinates

parameters:
  - name: type_name
    type: string
    choices_from: family_types:OST_StructuralColumns
  - name: level_name
    type: string
    choices_from: levels
  - name: x
    type: double
    description: X coordinate (mm)

code_template: |
  // Queries Revit for live data — no hardcoded values
  var symbol = collector
    .FirstOrDefault(s => s.Name == "{type_name}");

VII Operational Logic

First Query

Full pipeline: rewrite → embed → search → rerank → generate → sandbox → execute. LLM-intensive, ~15-30 seconds total. Code generated from scratch using RAG context.

Repeated Query

Matching solidified tool loads YAML template, fills parameters from user input or Revit live data, and executes directly. Zero LLM cost, sub-second.

Compile Failure

Roslyn errors fed back to Claude with original context. Auto-retry generates corrected code — up to 2 attempts. Most errors resolve on first retry.

API Explorer

Standalone search mode — browse the 27,596 API entries interactively. Results as ranked tables with syntax, parameters, and remarks. Click any API to generate a runnable code example.

Intent Bridge

Specialized slot-filling middleware. LLM classifies interaction type — direct query, family selection, element picking, or composite — and routes through the appropriate parameter flow.
