# 术语映射表 — 设计师语言 → AI 精确术语

## 怎么用这个表

当你描述需求时，如果不确定某个概念该怎么说，在这里找到对应的精确术语。
AI 能理解两列中的任何一种说法，但右列的说法会让 AI 更快理解你的意图。

## 尺寸与位置

| 设计师常说 | AI 需要的精确信息 |
|-----------|----------------|
| 大的 / 大一点 | 具体尺寸（mm） |
| 标准的 | 让 AI 列出项目中的可用类型 |
| 高一些 / 矮一点 | 具体高度值（mm） |
| 厚墙 / 薄墙 | 具体厚度：100 / 150 / 200 / 300mm |
| 这里 / 那里 | 在 Revit 中点选，或给出坐标/轴线 |
| 旁边 / 隔壁 | 具体偏移距离（mm）和方向 |
| 居中 / 正中间 | 相对于什么居中 + 方向 |
| 一层 / 二层 | 标高名称：F1 / F2 / 1F / 2F（因项目而异） |
| 从...到... | 起点坐标 + 终点坐标，或起点标高 + 终点标高 |

## 空间类型

| 设计师常说 | 包含的构件 | 关键参数 |
|-----------|----------|---------|
| 标准间 / 客房 | 墙 + 门 + 窗 + 房间 | 开间×进深、墙厚、门宽、窗宽 |
| 办公室 | 墙 + 门 + 窗 + 房间 | 面积、人数、隔墙类型 |
| 会议室 | 墙 + 门 + 房间 | 面积、人数、门的类型（单开/双开） |
| 走廊 | 墙 + 房间 | 宽度、长度、净高 |
| 卫生间 | 墙 + 门 + 房间 + 设备 | 面积、隔断数量 |
| 电梯厅 | 墙 + 门 + 房间 | 面积、电梯门数量 |
| 楼梯间 | 墙 + 楼梯 + 楼板开口 + 栏杆 | 宽度、踏步数、层高 |

## 常见度量

| 术语 | 说明 | 常见值范围 |
|------|------|----------|
| 开间 | 房间短边方向的尺寸 | 2700 ~ 9000mm |
| 进深 | 房间长边方向的尺寸 | 3600 ~ 12000mm |
| 层高 | 楼板面到上层楼板面 | 2800 ~ 4500mm |
| 净高 | 楼板面到吊顶底面 | 2400 ~ 3600mm |
| 墙厚 | 墙体截面厚度 | 100 / 150 / 200 / 300mm |
| 窗台高 | 窗底到楼板面 | 900mm（办公/住宅） |
| 门高 | 门洞净高 | 2100 / 2400mm |
| 踏步高 | 楼梯每级高度 | 150 ~ 175mm |
| 踏步宽 | 楼梯每级宽度 | 260 ~ 300mm |
