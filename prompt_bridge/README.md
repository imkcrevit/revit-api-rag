# PromptBridge — 设计师提示词优化模块

## 这是什么？

PromptBridge 是设计师与 AI 之间的**提示词翻译层**。

设计师不需要了解 Revit API、参数名称或 AI 的工作方式。他们只需要用自己的语言描述需求，PromptBridge 会帮助他们把模糊的想法转化为 AI 可以精确执行的结构化提示。

```
设计师说的          PromptBridge 优化后
─────────────────  ──────────────────────────────────
"做个标准间"        "创建一个 3600×5400mm 的标准客房，
                    墙体厚度 200mm，层高 2900mm，
                    含一扇 900×2100mm 入户门"

"加根梁"           "在 A 轴到 B 轴之间放置一根结构梁，
                    截面 300×600mm，底标高 3000mm，
                    梁类型选择项目中已有的混凝土矩形梁"

"这排窗户间距不对"   "查询当前视图中所有窗户元素，
                    检查相邻窗户中心间距是否等于 1800mm，
                    标记不符合的窗户"
```

## 模块结构

```
prompt_bridge/
├── README.md                  ← 你正在读的文件
├── _guide.md                  ← 设计师使用指南（怎样提问更高效）
├── glossary.md                ← 设计师术语 → AI 术语映射表
└── scenarios/                 ← 按场景分类的提示词优化卡片
    ├── room_creation.md       ← 房间/空间创建
    ├── wall_operations.md     ← 墙体操作
    ├── element_placement.md   ← 构件放置（门窗柱梁家具）
    ├── element_query.md       ← 元素查询与检查
    ├── modification.md        ← 修改与调整
    └── layout_design.md       ← 综合布局设计
```

## 怎么用？

### 对设计师

1. 先看 `_guide.md`，了解"好提问"的几个要素
2. 找到最接近你需求的场景卡片（`scenarios/`）
3. 参考卡片中的**优化示例**，补全你的描述
4. 不确定该怎么说？查 `glossary.md` 找到正确的术语

### 对 AI / 系统集成

PromptBridge 的场景卡片可以作为 skill 的补充上下文注入 LLM prompt，帮助 LLM 在收到模糊输入时主动引导用户补全参数。

## 设计原则

1. **不教 API，教表达** — 设计师不需要知道 `Wall.Create` 或 `NewFamilyInstance`，只需要学会说清楚"什么东西、放哪里、多大"
2. **从模糊到精确** — 每个场景卡片都展示从模糊语言到精确提示的转化路径
3. **对齐 Skill 体系** — 每个场景卡片标注了对应的 skill pattern/standard，确保优化后的提示与系统能力对齐
4. **双语支持** — 所有术语和示例提供中英对照
