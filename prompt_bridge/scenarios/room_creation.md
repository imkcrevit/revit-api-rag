# 房间/空间创建 — 场景卡片

> 关联 Skill: `patterns/line_based` · `patterns/hosted` · `patterns/composite` · `standards/office_layout`

## 场景总览

创建一个完整的房间通常是**复合操作**（创建围合墙体 → 开门/窗 → 创建房间对象），即使设计师只说了一句话。

---

## 场景 1：标准客房

### 设计师可能说的
- "做个标准间"
- "创建一个客房"
- "画一个酒店房间"

### 缺失信息分析
| 需要知道 | 设计师没说 | 为什么重要 |
|---------|-----------|----------|
| 开间×进深 | 没给尺寸 | 无法确定墙体长度和位置 |
| 墙体厚度 | 没指定 | 影响净空面积 |
| 层高 | 没指定 | 影响墙高和门窗放置 |
| 门的位置和尺寸 | 没说 | 客房必须有入户门 |
| 窗的位置和尺寸 | 没说 | 客房通常有窗 |
| 放在哪个标高 | 没说 | 必须指定楼层 |
| 放在什么位置 | 没说 | 需要起始坐标 |

### 优化后的提示
```
在 [标高] 层创建一个标准客房：
- 开间 3600mm × 进深 5400mm
- 墙体厚度 200mm，层高 2900mm
- 南面墙居中位置开一扇 900×2100mm 单开门
- 北面墙居中位置开一扇 1500×1500mm 窗，窗台高 900mm
- 起始角点坐标：(X, Y)
```

### 设计师实际该怎么说
> "在 F3 层做一个 3.6×5.4 米的标准客房，墙厚 200，南面开一扇 900 宽的门，北面开一扇 1500 宽的窗"

AI 会自动追问：具体位置（坐标或点选）、墙类型选择、标高确认。

## 场景 2：办公室

### 设计师可能说的
- "做一个办公室"
- "创建一间双人办公室"
- "隔一个工位出来"

### 优化后的提示
```
在 [标高] 层创建一间双人办公室：
- 面积不小于 14㎡（推荐 18㎡），如 4000×4500mm
- 隔墙使用 100mm 轻钢龙骨
- 一扇 900×2100mm 单开门
- 一扇窗（尺寸和位置待定）
- 起始角点坐标：(X, Y)
```

### 参数速查（来自 office_layout 标准）
| 办公室类型 | 最小面积 | 推荐面积 | 隔墙 | 门 |
|-----------|---------|---------|------|-----|
| 单人办公室 | 9㎡ | 12㎡ | 100mm 轻钢龙骨 | 单开 900mm |
| 双人办公室 | 14㎡ | 18㎡ | 100mm 轻钢龙骨 | 单开 900mm |
| 4人会议室 | 10㎡ | 15㎡ | 100mm 轻钢龙骨 | 单开 1000mm |
| 8人会议室 | 20㎡ | 25㎡ | 100mm 轻钢龙骨 | 双开 |

## 场景 3：走廊

### 设计师可能说的
- "画一条走廊"
- "做个过道"
- "连接两个房间的通道"

### 优化后的提示
```
在 [标高] 层创建一条走廊：
- 长度 [L]mm，净宽不小于 1500mm（推荐 1800mm）
- 两侧使用 200mm 隔墙
- 净高 2400mm
- 起点坐标 (X1, Y1)，终点坐标 (X2, Y2)
```

## 场景 4：卫生间

### 设计师可能说的
- "做个卫生间"
- "加一个洗手间"

### 优化后的提示
```
在 [标高] 层创建一间卫生间：
- 面积 [W×D]mm（最小 4㎡）
- 墙体厚度 200mm（防水要求）
- 一扇 800×2100mm 单开门（外开）
- 无窗 / 含排风口
- 起始角点坐标：(X, Y)
```

## 通用参数检查清单

创建任何房间时，确认以下信息：

- [ ] 房间用途（决定面积标准和配置）
- [ ] 开间 × 进深（mm）
- [ ] 墙体厚度和类型
- [ ] 层高 / 墙高
- [ ] 门的数量、尺寸、位置
- [ ] 窗的数量、尺寸、位置（如需要）
- [ ] 放置标高
- [ ] 起始坐标或参考位置
