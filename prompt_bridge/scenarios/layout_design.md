# 综合布局设计 — 场景卡片

> 关联 Skill: `patterns/composite` · `standards/office_layout` · `standards/mep_routing`

## 核心概念

布局设计是最复杂的场景——设计师用一两句话描述的"空间"，实际上需要**多步骤、多构件**的组合操作。PromptBridge 在这里的价值最大：帮设计师把整体愿景拆解为 AI 可以逐步执行的精确指令。

---

## 场景 1：办公区域布局

### 设计师可能说的
- "帮我布置一个办公区"
- "做一层办公室的布局"
- "规划一下这个区域"

### 这句话背后的复杂度
```
"布置一个办公区" 实际包含：
├── 确定整体区域范围
├── 规划功能分区（办公室、会议室、茶水间、走廊）
├── 每个分区：
│   ├── 创建围合墙体
│   ├── 开门（大小按用途）
│   ├── 开窗（如需要）
│   └── 创建房间对象
└── 公共走廊连接各区域
```

### 优化后的提示
```
在 [标高] 层规划办公区域，整体范围 [长×宽]mm：

区域 1 — 走廊：
- 位于中部，宽 1800mm，贯穿东西
- 墙厚 200mm

区域 2 — 单人办公室 × 4：
- 走廊北侧，每间 3000×4000mm
- 隔墙 100mm，每间一扇 900mm 单开门朝走廊

区域 3 — 8人会议室 × 1：
- 走廊南侧西端，5000×5000mm
- 隔墙 100mm，双开门朝走廊

区域 4 — 茶水间 × 1：
- 走廊南侧东端，3000×3000mm
- 隔墙 100mm，900mm 单开门

起点坐标：(X, Y)
```

### 设计师实际该怎么说（分步）

不需要一次说完。可以分步告诉 AI：

1. "在 F1 层做 4 间 3×4 米的单人办公室，排成一排，隔墙 100mm"
2. "在办公室对面做一间 5×5 米的会议室"
3. "中间留 1.8 米宽的走廊连通"
4. "走廊尽头加一间 3×3 米的茶水间"

## 场景 2：酒店标准层

### 设计师可能说的
- "做一层标准客房"
- "排一排酒店房间"

### 优化后的提示
```
在 [标高] 层创建酒店标准层客房排列：

单元参数：
- 标准客房：开间 3600mm × 进深 7200mm
- 墙厚：200mm（分户墙）/ 100mm（卫生间隔墙）
- 每间含：入户门 900mm（朝走廊）、外窗 1500mm
- 卫生间：1800×2400mm，位于入口侧

排列方式：
- 走廊两侧对称排列
- 走廊宽 1800mm
- 北侧 [N] 间，南侧 [N] 间
- 起始位置：(X, Y)
```

## 场景 3：单个功能房间（详细配置）

### 设计师可能说的
- "做一个完整的会议室"
- "创建一间带家具的办公室"

### 优化后的提示
```
在 [标高] 层创建一间完整的 8 人会议室：

空间：
- 尺寸：5000×5000mm
- 墙体：100mm 轻钢龙骨隔墙
- 层高：3000mm

门窗：
- 双开门 1200×2100mm，朝走廊方向
- 窗户（如有外墙面）：1800×1500mm，窗台高 900mm

家具（可选后续步骤）：
- 会议桌：2400×1200mm，房间居中
- 会议椅：8 把，环绕桌子

位置：起点 (X, Y)
```

## 场景 4：走廊+房间连接

### 设计师可能说的
- "把这些房间用走廊连起来"
- "加一条连通的走廊"

### 优化后的提示
```
创建连通走廊：
- 起点：(X1, Y1)  终点：(X2, Y2)
- 净宽：1800mm
- 墙厚：200mm
- 在以下位置开门连接已有房间：
  - 距起点 [D1]mm 处（连接房间 A）
  - 距起点 [D2]mm 处（连接房间 B）
  - ...
```

## 布局规划检查清单

### 前置信息
- [ ] 整体区域范围（长×宽，或在 Revit 中指定区域）
- [ ] 所在标高
- [ ] 功能需求（几间办公室、几间会议室等）

### 每个功能区
- [ ] 用途和面积（是否满足最小标准）
- [ ] 墙体类型和厚度
- [ ] 门的数量、类型、朝向
- [ ] 窗的需求
- [ ] 与走廊/其他区域的连接关系

### 走廊
- [ ] 宽度（≥ 1500mm）
- [ ] 路径（连接哪些区域）
- [ ] 开门位置

### 整体
- [ ] 各区域位置关系（相邻/对面/端头）
- [ ] 起始坐标或参考位置

## 复杂度管理建议

对于大型布局，建议分步进行而非一次性描述：

```
第一轮：描述整体分区和走廊
       → AI 创建走廊和围合墙体

第二轮：逐个区域补充细节
       → AI 在已有墙体上开门、放窗

第三轮：配置内部（如需要）
       → AI 放置家具、设备
```

> 每一轮都是独立的对话，AI 会基于当前模型状态执行。不用担心"忘记"之前的操作——构件已经在模型里了。
