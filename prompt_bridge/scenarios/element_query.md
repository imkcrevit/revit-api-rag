# 元素查询与检查 — 场景卡片

> 关联 Skill: `patterns/query` · `workflows/clearance_calculation` · `workflows/element_data_export`

## 核心概念

查询操作不创建或修改任何东西，只是**读取和分析**模型中的信息。
设计师需要说清楚：**查什么、在哪个范围、要什么结果**。

---

## 场景 1：统计数量

### 设计师可能说的
- "有多少墙？"
- "数一下柱子"
- "统计一下门的数量"

### 优化后的提示
```
查询 [范围] 中所有 [构件类型] 的数量：
- 范围：当前视图 / [标高]层 / 整个项目
- 构件类型：墙 / 柱 / 门 / 窗 / ...
- 筛选条件（可选）：类型名包含"xxx"/ 参数值 > N
- 输出方式：总数 / 按类型分组统计
```

### 设计师实际该怎么说
> "统计 F1 层所有门的数量，按门的类型分组"

---

## 场景 2：筛选特定元素

### 设计师可能说的
- "找出所有厚度超过 200mm 的墙"
- "哪些窗户宽度不到 1200？"
- "列出所有混凝土柱"

### 优化后的提示
```
查询 [范围] 中满足以下条件的 [构件类型]：
- 条件：[属性名] [> / < / = / 包含] [值]
- 输出：列出每个元素的 [需要的属性列表]
```

### 设计师实际该怎么说
> "找出当前视图中所有厚度大于 200mm 的墙，列出类型名和长度"

---

## 场景 3：检查间距/净高

### 设计师可能说的
- "梁底净高够不够？"
- "检查一下走廊宽度"
- "柱子间距是多少？"

### 优化后的提示（对应 clearance_calculation workflow）
```
检查 [范围] 中 [构件A] 与 [构件B] 之间的 [净高/间距]：
- 构件A：[类别，如结构梁]
- 构件B：[类别，如楼板]
- 测量方式：BoundingBox 差值 / 射线检测
- 合规标准（可选）：净高 ≥ [值]mm
- 输出：列出每对构件的测量值 + 是否合规
```

### 设计师实际该怎么说
> "检查 F2 层所有梁的梁底到楼板的净高，标记低于 2400mm 的"

---

## 场景 4：数据导出

### 设计师可能说的
- "把房间数据导出来"
- "导出所有门窗表"
- "输出一份构件清单"

### 优化后的提示
```
导出 [范围] 中所有 [构件类型] 的数据：
- 需要的字段：[类型名、标高、尺寸、数量、...]
- 输出格式：CSV / Excel / 对话框展示
- 排序方式（可选）：按 [字段] 排序
```

### 设计师实际该怎么说
> "把 F1 到 F5 层的所有房间数据导出为 CSV，包含房间名、面积、标高"

---

## 场景 5：合规性检查

### 设计师可能说的
- "检查一下办公室面积够不够"
- "走廊宽度合不合规"
- "会议室的门对不对"

### 优化后的提示（对应 office_layout 标准）
```
按照办公空间布局规范检查 [范围]：
- 检查项：
  □ 各房间面积是否达到最小标准
  □ 走廊宽度是否 ≥ 1500mm
  □ 办公室是否有门和窗
  □ 8人以上会议室是否使用双开门
- 输出：合规/不合规清单 + 改进建议
```

---

## 查询类型决策树

```
你要做什么？
├── 数数量 → 统计查询（场景1）
├── 找特定的 → 筛选查询（场景2）
├── 量尺寸/间距 → 几何检查（场景3）
├── 导数据 → 数据导出（场景4）
└── 查合不合规 → 合规检查（场景5）
```
