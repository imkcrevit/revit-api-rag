# 墙体操作 — 场景卡片

> 关联 Skill: `patterns/line_based` · `standards/office_layout`

## 核心概念

墙是**线性构件**（line_based）：由一条基线（起点→终点）+ 高度 + 类型定义。
设计师需要说清楚的最小信息集：**从哪到哪、多高、什么类型**。

---

## 场景 1：创建单面墙

### 设计师可能说的
- "画一面墙"
- "做一堵 6 米的墙"
- "建个隔断"

### 缺失信息分析
| 需要知道 | 为什么 |
|---------|--------|
| 起点和终点坐标 | 定义墙的位置和长度 |
| 墙体类型/厚度 | 不同用途墙体不同 |
| 标高 | 放在哪一层 |
| 墙高（可选） | 默认跟随层高，但可能需要自定义 |

### 模糊 → 优化
```
模糊："画一面 6 米的墙"
优化："在 F1 层从坐标 (0, 0) 到 (6000, 0) 创建一面墙，
       墙体类型：200mm 混凝土墙，高度：3000mm"
```

### 设计师实际该怎么说
> "在 F1 层画一面 6 米长的 200 厚墙，从 A1 轴到 A2 轴"

或者更简单：
> "在 F1 层画一面 200 厚的墙，我来点选起点和终点"

---

## 场景 2：创建围合墙体（矩形）

### 设计师可能说的
- "画一圈墙"
- "围一个 4×5 的空间"
- "做四面墙围起来"

### 优化后的提示
```
在 [标高] 层创建矩形围合墙体：
- 外轮廓尺寸：4000×5000mm
- 墙体类型：[从项目中选择]
- 墙高：3000mm
- 左下角起点：(X, Y)
```

> AI 会自动拆分为 4 面墙的创建操作，用 composite action_plan 处理。

---

## 场景 3：修改墙体

### 设计师可能说的
- "把这面墙加高"
- "改一下墙的厚度"
- "把墙移过去一点"

### 优化后的提示

**改高度：**
```
将 [选中的墙] 的无连接高度从当前值改为 3600mm
```

**改类型：**
```
将 [选中的墙] 的墙体类型更改为 [目标类型，从项目中选择]
```

**移动：**
```
将 [选中的墙] 沿 [X/Y 轴] 方向平移 [距离]mm
```

---

## 场景 4：墙上开洞

### 设计师可能说的
- "在这面墙上开个洞"
- "墙上挖个口子"

### 优化后的提示
```
在 [选中的墙] 上创建一个矩形开口：
- 开口宽度：[W]mm
- 开口高度：[H]mm
- 底边距楼板：[距离]mm
- 距墙左端：[距离]mm
```

## 墙体类型速查

| 用途 | 推荐厚度 | 说明 |
|------|---------|------|
| 外墙 | 200 ~ 300mm | 结构墙，含保温 |
| 内隔墙（办公） | 100mm | 轻钢龙骨隔墙 |
| 走廊墙 | 200mm | 较厚隔墙 |
| 卫生间墙 | 200mm | 防水墙体 |
| 分户墙 | 200 ~ 250mm | 隔声要求 |
| 幕墙 | — | 单独类别，非普通墙 |

## 参数检查清单

- [ ] 起点坐标和终点坐标（或长度+方向）
- [ ] 墙体类型 / 厚度
- [ ] 放置标高
- [ ] 墙高（无连接高度 或 顶部约束标高）
- [ ] 是否为结构墙
