# 构件放置 — 场景卡片

> 关联 Skill: `patterns/point_based` · `patterns/hosted` · `patterns/line_based`

## 放置模式一览

| 模式 | 适用构件 | 关键参数 |
|------|---------|---------|
| 点放置 (point_based) | 柱、家具、设备、灯具 | 坐标点 + 标高 + 族类型 |
| 宿主放置 (hosted) | 门、窗 | 宿主墙 + 偏移位置 + 族类型 |
| 线放置 (line_based) | 梁、栏杆 | 起点 + 终点 + 标高 + 族类型 |

---

## 场景 1：放置柱子

### 设计师可能说的
- "放一根柱子"
- "在轴线交点放柱子"
- "加几根结构柱"

### 优化后的提示
```
在 [标高] 层放置 [数量] 根结构柱：
- 柱类型：[从项目中选择，如 400×400mm 混凝土柱]
- 位置：[轴线交点 / 坐标列表]
- 底标高：[标高名]
- 顶标高：[标高名]（或无连接高度 [H]mm）
```

### 设计师实际该怎么说
> "在 F1 层 A1、A2、A3 轴交点各放一根 400×400 混凝土柱，柱高到 F2 层"

---

## 场景 2：放置门

### 设计师可能说的
- "开一扇门"
- "加个门"
- "在这面墙上放一扇门"

### 缺失信息
| 需要知道 | 为什么 |
|---------|--------|
| 宿主墙 | 门必须放在墙上 |
| 门的类型和尺寸 | 单开/双开、宽度、高度 |
| 在墙上的位置 | 距墙端的偏移，或居中 |

### 优化后的提示
```
在 [选中的墙/点选墙] 上放置一扇门：
- 门类型：[从项目中选择，如 单开门 900×2100mm]
- 位置：距墙左端 [距离]mm / 居中 / 点选位置
```

### 设计师实际该怎么说
> "在这面墙上居中放一扇 900 宽的单开门"（然后在 Revit 中点选墙）

---

## 场景 3：放置窗户

### 设计师可能说的
- "开个窗"
- "加一排窗户"
- "装三扇窗"

### 优化后的提示

**单扇窗：**
```
在 [选中的墙] 上放置一扇窗：
- 窗类型：[从项目中选择，如 固定窗 1500×1500mm]
- 窗台高：900mm
- 位置：距墙左端 [距离]mm / 居中
```

**一排窗（等间距）：**
```
在 [选中的墙] 上等间距放置 [N] 扇窗：
- 窗类型：[从项目中选择]
- 窗台高：900mm
- 首扇距墙左端 [距离]mm，间距 [间距]mm
```

## 场景 4：放置家具

### 设计师可能说的
- "放一张桌子"
- "摆几把椅子"
- "配置办公家具"

### 优化后的提示
```
在 [标高] 层放置家具：
- 族类型：[从项目中选择]
- 位置：坐标 (X, Y) / 点选位置
- 旋转角度：[0/90/180/270 度]
```

---

## 场景 5：放置结构梁

### 设计师可能说的
- "加一根梁"
- "在两柱之间拉一根梁"

### 优化后的提示
```
在 [标高] 层放置一根结构梁：
- 梁类型：[从项目中选择，如 矩形梁 300×600mm]
- 起点：(X1, Y1)  终点：(X2, Y2)
- 底标高偏移：[距离]mm（梁底距标高的距离）
```

### 设计师实际该怎么说
> "在 F2 层从 A1 到 B1 拉一根 300×600 的梁，梁底标高 3000mm"

## 各构件参数检查清单

### 柱
- [ ] 柱类型（截面尺寸、材料）
- [ ] 放置点坐标
- [ ] 底标高 / 顶标高
- [ ] 是否结构柱

### 门/窗（hosted）
- [ ] 宿主墙（点选）
- [ ] 族类型（尺寸）
- [ ] 在墙上的位置
- [ ] 窗台高（仅窗）

### 梁（line_based）
- [ ] 梁类型（截面尺寸）
- [ ] 起点 / 终点
- [ ] 标高 / 标高偏移
- [ ] 结构用途

### 家具/设备（point_based）
- [ ] 族类型
- [ ] 放置点坐标
- [ ] 标高
- [ ] 旋转角度
