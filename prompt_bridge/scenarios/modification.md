# 修改与调整 — 场景卡片

> 关联 Skill: `patterns/modify` · `patterns/delete`

## 核心概念

修改操作作用于**已存在的元素**。设计师需要说清楚：**改哪个、改什么、改成什么值**。

大多数修改操作需要先**选中目标元素**（在 Revit 中点选），然后告诉 AI 要做什么调整。

---

## 场景 1：移动

### 设计师可能说的
- "把这个移一下"
- "柱子往右挪 1 米"
- "把门移到墙中间"

### 缺失信息
| 需要知道 | 为什么 |
|---------|--------|
| 移哪个元素 | 需要点选或指定 |
| 移动方向 | "右"取决于视角 |
| 移动距离 | 具体数值 |

### 优化后的提示
```
将 [选中的元素] 沿 [方向] 平移 [距离]mm
- 方向：X轴正方向 / Y轴正方向 / 指定向量 (dx, dy, dz)
- 距离：[N]mm
```

### 设计师实际该怎么说
> "把选中的柱子沿 X 方向移动 1000mm"

或更直观：
> "把这根柱子向东移 1 米"（需要确认项目北方向）

---

## 场景 2：旋转

### 设计师可能说的
- "转一下"
- "旋转 90 度"
- "把这个家具转个方向"

### 优化后的提示
```
将 [选中的元素] 绕 [旋转中心] 旋转 [角度] 度
- 旋转中心：元素自身中心 / 指定点 (X, Y)
- 角度：[N] 度（正值=逆时针）
```

### 设计师实际该怎么说
> "把选中的桌子顺时针旋转 90 度"

---

## 场景 3：修改参数

### 设计师可能说的
- "把墙改高一点"
- "改一下门的宽度"
- "把楼板厚度改成 150"

### 优化后的提示
```
将 [选中的元素] 的 [参数名] 修改为 [新值]
```

### 常见参数对照

| 设计师说的 | 实际参数 | 适用构件 |
|-----------|---------|---------|
| 高度、墙高 | 无连接高度 / Unconnected Height | 墙 |
| 厚度 | 类型参数（需换类型） | 墙、楼板 |
| 宽度 | Width | 门、窗 |
| 高度 | Height | 门、窗 |
| 底标高 | Base Level / Base Offset | 柱、墙 |
| 顶标高 | Top Level / Top Offset | 柱、墙 |
| 偏移 | Offset | 各种构件 |

> 注意：有些"修改"其实是**换类型**（如改墙厚），不是改参数值。AI 会识别并引导。

---

## 场景 4：复制

### 设计师可能说的
- "复制一个"
- "再来三个一样的"
- "把这排柱子复制到上一层"

### 优化后的提示
```
复制 [选中的元素]：
- 数量：[N] 个
- 偏移方向和距离：(dx, dy, dz)mm
- 或：复制到 [目标标高]
```

### 设计师实际该怎么说
> "把选中的柱子沿 X 方向复制 4 个，间距 6000mm"

---

## 场景 5：镜像

### 设计师可能说的
- "翻转一下"
- "做个对称的"
- "镜像到另一边"

### 优化后的提示
```
将 [选中的元素] 关于 [镜像轴] 做镜像：
- 镜像轴：通过点 (X1,Y1) 和 (X2,Y2) 的直线
- 是否保留原始元素：是 / 否
```

---

## 场景 6：删除

### 设计师可能说的
- "删掉这个"
- "把多余的墙去掉"
- "清理一下这些元素"

### 优化后的提示
```
删除 [选中的元素 / 满足条件的元素]
- 选择方式：点选 / 按条件筛选
- 条件（如筛选）：[构件类型] + [属性条件]
```

> 批量删除前，AI 会先查询匹配的元素数量并确认。

---

## 操作 → 所需信息速查

| 操作 | 必须知道 | 可选 |
|------|---------|------|
| 移动 | 元素 + 方向 + 距离 | — |
| 旋转 | 元素 + 角度 | 旋转中心 |
| 修改参数 | 元素 + 参数 + 新值 | — |
| 复制 | 元素 + 偏移/目标 | 数量 |
| 镜像 | 元素 + 镜像轴 | 保留原始 |
| 删除 | 元素 | 确认提示 |

## 参数检查清单

- [ ] 目标元素（点选 或 筛选条件）
- [ ] 操作类型（移动/旋转/修改/复制/镜像/删除）
- [ ] 操作参数（距离/角度/新值/偏移量）
- [ ] 方向或参考（轴向/旋转中心/镜像轴）
