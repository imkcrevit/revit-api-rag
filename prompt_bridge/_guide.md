# 设计师提问指南 — 怎样让 AI 更好地理解你

## 核心原则：说清三件事

无论你要做什么操作，AI 最需要知道的是：

| 要素 | 说明 | 示例 |
|------|------|------|
| **做什么** | 操作类型 + 目标构件 | 创建墙、放置门、查询柱子 |
| **在哪里** | 位置、标高、宿主 | 在 F1 层、在这面墙上、坐标(0,0,0) |
| **多大/什么样** | 尺寸、类型、属性 | 厚度 200mm、宽 900mm、混凝土柱 |

> 如果你只说了"做什么"，AI 会逐个追问其余信息。说得越完整，对话轮次越少。

## 好提问 vs 模糊提问

### 创建类

| 模糊 | 好 | 更好 |
|------|-----|------|
| 建个墙 | 建一面 6000mm 长的墙 | 在 F1 层建一面 6000mm 长、3000mm 高的 200mm 混凝土墙，起点(0,0)到(6000,0) |
| 放扇门 | 在这面墙上放一扇 900mm 宽的门 | 在这面墙上放一扇 900×2100mm 的单开门，距墙左端 1200mm |
| 做个房间 | 做一个 4×5m 的办公室 | 做一个 4000×5000mm 的双人办公室，墙厚 100mm，含一扇门一扇窗 |

### 查询类

| 模糊 | 好 | 更好 |
|------|-----|------|
| 有多少墙 | 查询当前视图中的所有墙 | 查询 F1 层所有厚度大于 200mm 的墙，列出类型和长度 |
| 看看柱子 | 查询项目中所有结构柱 | 查询 F1 到 F3 层之间的所有混凝土柱，按标高分组统计数量 |

### 修改类

| 模糊 | 好 | 更好 |
|------|-----|------|
| 移一下 | 把这根柱子向右移 1000mm | 把选中的柱子沿 X 轴正方向平移 1000mm |
| 改个高度 | 把这面墙的高度改为 3600mm | 把选中的墙的无连接高度改为 3600mm |

## 常见陷阱

### 1. 方位词歧义

"左边""右边""前面""后面"取决于你看的视角，AI 无法确定。

- 不好："把门放在左边"
- 好："把门放在北面墙上" 或 "把门放在 A 轴方向的墙上"
- 也好：直接在 Revit 中点选位置

### 2. "标准"/"默认"/"常规"

这些词对 AI 来说没有具体含义，因为每个项目的标准可能不同。

- 不好："用标准墙"
- 好："用 200mm 混凝土墙" 或 让 AI 列出项目中的墙类型供你选

### 3. 隐含的多步操作

有些听起来是一步的操作，其实需要多步完成。说清楚你期望的完整结果：

- "做个办公室" 其实包含：创建围合墙 → 开门 → 开窗 → 创建房间
- "加个楼梯间" 其实包含：创建墙 → 创建楼板开洞 → 放置楼梯 → 加栏杆

### 4. 数量不明确

- 不好："加几根柱子"
- 好："在 A1-A5 轴交点处各放一根柱子，共 5 根"

## 提问模板

遇到不确定怎么问时，可以套用以下模板：

### 创建构件
```
在 [标高] 层创建 [数量] 个 [类型描述] 的 [构件名称]，
尺寸为 [长×宽×高]，
位置在 [坐标/参考点/轴线交点]
```

### 查询信息
```
查询 [范围：当前视图/某层/整个项目] 中的所有 [构件类型]，
筛选条件：[属性] [大于/等于/小于] [值]，
输出：[需要看到的信息]
```

### 修改元素
```
将 [选中的/指定的] [构件] 的 [属性] 从 [当前值] 改为 [目标值]
```

### 综合布局
```
在 [标高] 层的 [位置范围] 创建一个 [用途] 空间，
整体尺寸 [长×宽]mm，
包含：[构件列表及各自要求]
```

## 不需要说的

以下信息你**不需要**提供，AI 会自动处理：

- Revit API 方法名（如 `Wall.Create`）
- 代码层面的参数名（如 `StructuralType`）
- ElementId 或内部单位
- 事务(Transaction)相关的操作
- 坐标系转换细节

你只需要用**建筑设计语言**描述你的需求。
