# 企业规范 Skills — 使用说明

本目录存放团队/企业自定义的 BIM 规范文件。

## 谁来写？

**BIM 工程师**就可以编写和维护这些文件，不需要编程知识。

## 怎么写？

1. 在本目录新建一个 `.md` 文件（如 `防火分区规范.md`）
2. 用中文写清楚规范内容
3. 保存即生效，不需要重启服务

## 格式要求

- 普通 Markdown 文件，用中文即可
- 文件名就是规范名称
- **必须包含「触发关键词」段落**，系统靠这些词匹配你的规范
- 建议结构：

```markdown
# 规范名称

简要说明这个规范的适用场景。

## 触发关键词
中文：关键词1、关键词2、关键词3
English: keyword1, keyword2, keyword3

## 具体规则
（写清楚数值、标准、优先级等）

## 创建时的规则
（创建构件时代码应该遵守什么）

## 检查时的规则
（检查合规性时怎么判断）
```

## 触发方式

用户说出相关关键词时，系统会自动加载匹配的规范文件。
例如用户说「排布暖通管道」→ 自动加载 `mep_routing.md`。

## 示例文件

- `mep_routing.md` — 管线综合排布规范（间距、优先级、避让规则）
