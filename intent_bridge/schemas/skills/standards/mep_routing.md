# 管线综合排布规范

本规范定义暖通、给排水、电气管线的排布标准。
当用户请求创建或排布管线时，生成的代码必须遵守以下规则。
当用户请求检查管线时，按以下规则进行碰撞检测和合规检查。

## 触发关键词
中文：管线、管道、排布、暖通、给排水、风管、桥架、碰撞检测、管综、净距、避让、喷淋、排烟
English：MEP, routing, pipe routing, duct routing, clash detection, clearance

## 管道优先级（从上到下）

| 优先级 | 管道类型 | 距顶板最小距离 | 说明 |
|--------|---------|--------------|------|
| 1（最高）| 排烟风管 | 50mm | 消防优先，不可避让 |
| 2 | 空调风管 | 排烟下方 100mm | 截面大，优先占位 |
| 3 | 喷淋管道 | 风管下方 50mm | 消防系统 |
| 4 | 空调水管 | 喷淋下方 100mm | |
| 5 | 给排水管 | 空调水管下方 100mm | |
| 6（最低）| 电缆桥架 | 最底层 | 可弯折，最容易避让 |

## 间距要求

- **平行管道最小净距**：100mm
- **交叉管道上下净距**：50mm
- **管道距墙面最小距离**：200mm
- **管道距梁底最小距离**：50mm
- **检修空间**：主管道上方预留 300mm 检修空间

## 避让规则

当管线发生碰撞时，按以下顺序避让：
1. 小管让大管（截面积小的避让大的）
2. 有压让无压（有压管道可以绕行，无压管道靠重力排水）
3. 电让水、水让风（电缆最灵活，风管最不灵活）
4. 新建让已建（后施工的避让先施工的）

## 创建时的规则

当用户要求创建管线时，代码必须：
1. 根据管道类型查表确定标高偏移量
2. 从楼层顶板标高开始，按优先级向下排列
3. 平行管道之间保持 100mm 净距
4. 生成代码中以注释标注：`// 标高计算：顶板 - {距顶板距离} - {管道半径}`

## 检查时的规则

当用户要求检查管线碰撞或合规性时：
1. 用 `FilteredElementCollector` 收集当前视图/楼层所有 MEP 管线
2. 检查项目（返回不合规列表）：
   - [ ] 各管道标高是否符合优先级顺序
   - [ ] 平行管道净距 ≥ 100mm
   - [ ] 交叉管道净距 ≥ 50mm
   - [ ] 距墙面 ≥ 200mm
   - [ ] 距梁底 ≥ 50mm
3. 返回格式：`{ element_id, 问题描述, 建议修复方案 }`

## 自动修复规则

当用户要求自动调整管线时：
1. 低优先级管道避让高优先级管道
2. 调整标高保持间距要求
3. 返回调整报告：`{ 调整了N根管道, 详细列表 }`
